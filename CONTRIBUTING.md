# Contributing to StaticDesk

Thanks for your interest in StaticDesk!

## Getting started

1. Fork and clone the repository.
2. Install dependencies with `pnpm install` (Node.js 22+, pnpm 10).
3. Start the app with `pnpm dev`.

## Before opening a pull request

- Run `pnpm lint`, `pnpm typecheck`, `pnpm test` and `pnpm build`.
- Add or update tests for the behavior you change.
- If you change a published package (`packages/*`), add a changeset with `pnpm changeset`.
- Use [Conventional Commits](https://www.conventionalcommits.org/) for commit messages
  (`feat:`, `fix:`, `docs:`, `chore:`…).

## Reporting bugs and requesting features

Open an issue using the matching template. For questions, use GitHub Discussions.
